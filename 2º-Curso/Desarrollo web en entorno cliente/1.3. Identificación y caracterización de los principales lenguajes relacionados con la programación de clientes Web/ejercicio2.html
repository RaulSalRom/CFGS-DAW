Ejercicio 2: Expresión de función (Function Expression)

Se asigna una función (normalmente anónima) a una variable o constante. No se puede usar antes de definirla, a diferencia de la declaración tradicional.

Apartado A - Función duplicar

Apartado B - Funciona repetidamente con el mismo bloque

Se define una vez y se invoca tantas veces como se necesite, sin duplicar código.
