Ejercicio 7: variable no declarada

Este archivo carga calculo.js. Abre la consola con F12 (pestaña Consola), recarga la página (F5) y observa:

  1. Los mensajes 1. y 2. se muestran con normalidad.
  2. Los mensajes 3. y 4. no aparecen: el intérprete se detuvo en la instrucción fallida.
  3. La consola muestra el error en rojo: Uncaught ReferenceError: descuento is not defined

Nota: un error sintáctico (por ejemplo, un paréntesis sin cerrar) impediría que el script se ejecutara siquiera. Un ReferenceError solo puede detectarse cuando se alcanza la línea, es decir, en tiempo de ejecución: esa es la diferencia entre un lenguaje compilado y uno interpretado.
