# Unidad 1: Introduccion al CMS y CDMON
## 1.1 ¿Que es un CMS?
Un CMS es una aplicacion web que permite la creacion, la gestion y la modificacion de contenido digital sin necesidad de tener conocimientos tecnicos especializados en programacion.

Caracteristicas:
·Interfaz intuitiva: Panel de administración amigable.
·Separación contenido-diseño: Los cambios del diseño no afectan al contenido.
·Gestion de usuarios: Diferentes roles y permisos
·Workflow de publicacion: Borrador, revision, publicacion.
·Extensiones: PLugins y temas para ampliar funcionalidades.

Flujo de trabajo tipico:
USuario --> Panel Admin --> CMS --> Base de datos --> Sitio web publicado

### 1.1.1 Arquitectura de un CMS. ¿Como funciona por dento?
Componentes esenciales:
·Base de datos: Almacena todo el contenido y configuraciones.
·Backend: Panel de administración para gestionar el contenido.
·Frontend: PArte visible para los visitantes del sitio.
·Tema/Plantilla: Define la apariencia visual.
·Módulos/Plugins: Añaden funcionalidades específicass.

Ventaja clave --> El usuario solo interactúa con el backend, el CMS se encarga de generar el frontend automaticamente.

### 1.1.2 Tipos de CMS
-Según su licencia:
    ·OpenSource: WordPress, Joomla, Drupal(Gratuitos y de codigo abierto).
    ·Propietarios: Adobe Experience Manager, Sitecore(De pago, codigo cerrado).
-Según su propósito:
    ·Blogs y sitios web: WordPress, Ghost.
    ·E-commerce: WooCommerce, PrestaShop, Magento.
    ·Portales empresariales: Drupal, Liferay.
-Según su tecnología;
    ·PHP: WordPress, Joomla, Drupal
    ·.NET: UMbraco, Sitecore
    ·Java: Liferay, OpenCMS

## 1.3 CMS vs Desarrollo a medida
| CMS (WordPress) | Desarrollo a medida |
|---|---|
| Rápida implementación | Máxima personalización |
| Coste inicial bajo | Coste más elevado |
| Actualizaciones automáticas | Mantenimiento complejo |
| Comunidad de soporte | Control total del código |
| Limitaciones de diseño | Tiempo de desarrollo mayor |
| Dependencia de plugins | Optimización específica |
