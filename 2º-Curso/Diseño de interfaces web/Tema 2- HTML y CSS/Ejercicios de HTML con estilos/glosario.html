Glosario básico de DAW

Diez términos que todo desarrollador web debe dominar, con listas de definición (dl, dt y dd).

Fundamentos

HTML
HTML: lenguaje de marcado que estructura el contenido de una página. Su versión actual es HTML5 y trabaja con etiquetas como <article>, <nav> o <table>.
CSS
CSS: lenguaje de estilos que controla el aspecto visual. En esta actividad lo usamos dentro de la etiqueta <style>.
DOM
DOM: representación del documento como un árbol de objetos que JavaScript puede leer y modificar.
API
API: conjunto de operaciones que un servicio ofrece a otros programas. En DWEC trabajamos con la API fetch para descargar datos.
HTTP / HTTPS
Protocolos con los que el navegador y el servidor se comunican; la S de HTTPS significa secure: viaja cifrado.
URL
URL: dirección completa de un recurso, por ejemplo https://developer.mozilla.org/es/docs/Web/HTML.

Herramientas y conceptos

Navegador
Programa que interpreta HTML y muestra la página: Firefox, Chrome, Safari o Edge. Cada uno puede mostrar matices distintos, por eso se valida el código.
Servidor
Equipo que aloja la web y responde peticiones del navegador. En DAW los gestionamos con Apache, Docker o CI/CD.
Diseño responsivo
Maquetar para que la misma página se adapte a móvil, tablet y escritorio.
Git
Sistema de control de versiones: guarda la historia del proyecto. Su plataforma más usada es GitHub. © 2026 · sin coste: 0 €.
