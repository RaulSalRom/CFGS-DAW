Contenido incrustado — Tabla 6.1

Ejemplos de las etiquetas vistas en el epígrafe de contenido incrustado.

iframe

Documento HTML embebido. Ojo: hay que usar la URL /embed/, la de /watch/ no deja incrustarse.

video y source

Vídeo local con dos formatos: source elige el primero que soporte el navegador.

audio y source

Sonido embebido, también con dos formatos alternativos.

svg en línea

Gráfico vectorial escrito directamente en el HTML (no es un fichero externo).

img y picture

Imagen vectorial externa declarada con picture y su source.

object

Recurso externo con contenido de respaldo dentro de la etiqueta, por si el navegador no lo abre.

canvas

Lienzo de mapa de bits dibujado con JavaScript al final del documento.

Tu navegador no soporta la etiqueta canvas.

embed

Ejemplo de PDF embebido.
