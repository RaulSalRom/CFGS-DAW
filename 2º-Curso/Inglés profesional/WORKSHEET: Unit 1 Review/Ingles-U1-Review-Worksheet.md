## 1. A Development Project — Mixed tense gap fill

> Complete the text with the correct form of the verbs in brackets.

Our development team usually **1. `works`** *(work — Present Simple, hábito)* on several projects at the same time, but this month we **2. `are focusing`** *(focus — Present Continuous, temporal)* on a new website for an online clothing company. We **3. `started`** *(start — Past Simple, «six weeks ago»)* the project six weeks ago and, since then, we **4. `have completed`** *(complete — Present Perfect, «since then»)* most of the front-end. We **5. `have been working`** *(work — Present Perfect Continuous, «for the last two weeks»)* on the back-end for the last two weeks, and at the moment two developers **6. `are creating`** *(create — Present Continuous, «at the moment»)* the user authentication system.

Yesterday, however, we **7. `had`** *(have — Past Simple, «Yesterday»)* a serious problem. While one of the developers **8. `was testing`** *(test — Past Continuous, acción en progreso)* the registration form, the application suddenly **9. `stopped`** *(stop — Past Simple, acción que interrumpe)* responding. We discovered that someone **10. `had changed`** *(change — Past Perfect, acción anterior en el pasado)* an important configuration file earlier that morning. Fortunately, our system administrator **11. `had already created`** *(already / create — Past Perfect)* a backup, so we restored the previous version.

Today everything is working normally again and we **12. `have just finished`** *(just / finish — Present Perfect)* another complete test. Tomorrow morning, we **13. `are meeting`** *(meet — Present Continuous para citas agendadas, «as arranged»)* the client at 10:00, as arranged. This time next week, we **14. `will be testing`** *(test — Future Continuous, «This time next week»)* the final version of the website. I think the client **15. `will like`** *(like — Future Simple tras «I think»)* the new design and, by the end of the month, we **16. `will have completed`** *(complete — Future Perfect, «by the end of the month»)* the whole project.

## 2. Find the Bug — Grammar debugging

> Each sentence contains one tense mistake. Find it and correct it.

| # | Incorrect sentence (Bug) | Corrected sentence | Why? (Grammar rule) |
|---|---|---|---|
| 1 | ❌ *I am working for this company since 2024.* | ✅ **I have been working for this company since 2024.** | Con `since` / `for` para una acción que empezó en el pasado y continúa hoy se usa **Present Perfect Continuous**, no Present Continuous. |
| 2 | ❌ *We have deployed the new version yesterday.* | ✅ **We deployed the new version yesterday.** | Con expresiones de tiempo pasado cerrado (`yesterday`, `ago`, `last week`) es obligatorio **Past Simple**. |
| 3 | ❌ *The developer already left when I arrived.* | ✅ **The developer had already left when I arrived.** | Acción ocurrida **antes** que otra acción pasada (`when I arrived`) → **Past Perfect**. |
| 4 | ❌ *While I tested the application, the screen went black.* | ✅ **While I was testing the application, the screen went black.** | Acción larga en curso (`While...`) interrumpida por otra corta → **Past Continuous**. |
| 5 | ❌ *Our company is usually developing websites for small businesses.* | ✅ **Our company usually develops websites for small businesses.** | Rutinas y actividad habitual (`usually`) → **Present Simple**. |
| 6 | ❌ *I have been knowing JavaScript for three years.* | ✅ **I have known JavaScript for three years.** | `know` es un **stative verb** (verbo de estado): no admite tiempos continuos (`-ing`). |
| 7 | ❌ *Look at those error messages! The server will crash.* | ✅ **Look at those error messages! The server is going to crash.** | Predicción basada en **evidencia presente visible** (`Look at those error messages!`) → **`be going to`**. |
| 8 | ❌ *By next Monday, we will finish all the tests.* | ✅ **By next Monday, we will have finished all the tests.** | Acción que estará terminada **antes de una fecha límite futura** (`By next Monday`) → **Future Perfect**. |

## 3. Project Timeline Challenge

| Time | Event |
|---|---|
| **Monday 09:00** | Team starts redesigning the website |
| **Monday 12:00** | Designer finishes the homepage |
| **Monday 15:00** | Developers start programming the login system |
| **Tuesday 10:00** | Server crashes |
| **Tuesday 12:00** | Problem solved |
| **Wednesday 11:00** | Meeting with client |
| **Friday** | Security testing |
| **Next Monday** | Project deadline |

1. *By Monday at 12:30, the designer* **`had finished the homepage`**. *(Past Perfect)*
2. *At 16:00 on Monday, the developers* **`were programming the login system`**. *(Past Continuous)*
3. *When the server crashed on Tuesday, the developers* **`had been programming the login system`** *since Monday afternoon.* *(Past Perfect Continuous)*
4. *By Tuesday lunchtime, the team* **`had solved`** *the problem.* *(Past Perfect)*
5. *This time on Friday, they* **`will be testing`** *the security of the website.* *(Future Continuous)*
6. *By next Monday, they* **`will have finished`** *the project.* *(Future Perfect)*

## 4. Translation — Professional English

| # | Español | English Translation | Tense used |
|---|---|---|---|
| 1 | Normalmente comprobamos la página web antes de publicarla. | **We usually test / check the website before publishing it.** | Present Simple |
| 2 | Esta semana estamos trabajando en una aplicación nueva. | **This week we are working on a new application.** | Present Continuous |
| 3 | Llevamos tres horas intentando solucionar este problema. | **We have been trying to solve this problem for three hours.** | Present Perfect Continuous |
| 4 | Estaba comprobando el código cuando el ordenador se bloqueó. | **I was checking the code when the computer crashed / froze.** | Past Continuous + Past Simple |
| 5 | Cuando llegué, ya habían reiniciado el servidor. | **When I arrived, they had already restarted the server.** | Past Simple + Past Perfect |
| 6 | Mañana a las diez nos reunimos con el cliente. | **Tomorrow at ten we are meeting the client.** | Present Continuous (Arrangement) |
| 7 | A estas horas mañana estaremos probando la aplicación. | **This time tomorrow we will be testing the application.** | Future Continuous |
| 8 | Para el viernes habremos terminado el proyecto. | **By Friday we will have finished the project.** | Future Perfect |

## 5. Same Context, Different Meaning

| Pair | Situation | Sentence | Contrast of Tenses |
|---|---|---|---|
| **PAIR A** | **A:** Yesterday, you worked on the website from 9:00 to 12:00. You finished at 12:00.<br>**B:** You started working on the website three hours ago. You are still working on it now. | **A:** *I worked on the website from 9:00 to 12:00 yesterday.*<br>**B:** *I have been working on the website for three hours.* | **Past Simple** (acción terminada en el pasado) vs. **Present Perfect Continuous** (sigue activa en el presente). |
| **PAIR B** | **A:** You arrived at the office. Then the technicians fixed the server.<br>**B:** The technicians fixed the server first. You arrived later. | **A:** *When I arrived at the office, the technicians fixed the server.*<br>**B:** *When I arrived at the office, the technicians had already fixed the server.* | **Past Simple + Past Simple** (secuencia sucesiva) vs. **Past Simple + Past Perfect** (acción anterior a otra pasada). |
| **PAIR C** | **A:** Your team has decided to meet the client next week, but no exact appointment has been arranged.<br>**B:** The meeting is already in the calendar: Tuesday at 10:30. | **A:** *We are going to meet the client next week.*<br>**B:** *We are meeting the client on Tuesday at 10:30.* | **`be going to`** (intención/plan sin hora cerrada) vs. **Present Continuous** (cita fijada en agenda). |
| **PAIR D** | **A:** You expect the team to finish the website on Friday.<br>**B:** The client meeting is on Friday afternoon. You expect the website to be complete before the meeting. | **A:** *We will finish the website on Friday.*<br>**B:** *By Friday afternoon, we will have finished the website.* | **Future Simple** (ocurrirá el viernes) vs. **Future Perfect** (estará completado antes de ese momento). |
| **PAIR E** | **A:** Your team plans to test the application tomorrow.<br>**B:** Tomorrow at 11:00, the testing process will already be in progress. | **A:** *We are going to test the application tomorrow.*<br>**B:** *Tomorrow at 11:00, we will be testing the application.* | **`be going to`** (plan general para mañana) vs. **Future Continuous** (acción en curso a una hora exacta del futuro). |
