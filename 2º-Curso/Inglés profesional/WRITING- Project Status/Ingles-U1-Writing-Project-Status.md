## 1. Estructura y guía gramatical del Writing (4 párrafos)

**Situación:** Formas parte de un equipo de desarrollo web que trabaja en un proyecto para un cliente. Antes de la reunión semanal, tu *team leader* te pide redactar un informe breve de estado del proyecto (**150–180 palabras** en **4 párrafos**):

| Párrafo | Contenido obligatorio | Tiempos verbales objetivo |
|---|---|---|
| **1. THE PROJECT NOW** | ¿Cuál es el proyecto? ¿Qué hace normalmente tu equipo? ¿En qué estáis trabajando ahora mismo? | **Present Simple** + **Present Continuous** |
| **2. PROGRESS SO FAR** | ¿Qué habéis completado ya? ¿Qué sigue pendiente? ¿Cuánto tiempo lleváis trabajando en algo? | **Present Perfect** + **Present Perfect Continuous** |
| **3. A RECENT PROBLEM** | ¿Qué ocurrió recientemente? ¿Qué estabais haciendo en ese momento? ¿Qué había pasado antes y cómo lo solucionasteis? | **Past Simple** + **Past Continuous** + **Past Perfect** |
| **4. NEXT STEPS** | ¿Qué tenéis agendado con el cliente? ¿Cuáles son los próximos planes? ¿Qué habréis terminado antes de la fecha límite? | **Present Continuous (futuro)** + **`be going to`** + **Future Perfect / Future Continuous** |

---

## 2. Banco de conectores (Connector Bank)

- **Párrafo 1 (NOW):** *In general · usually · normally · at the moment · currently · while*
- **Párrafo 2 (PROGRESS):** *So far · up to now · however · also · in addition · apart from that · yet*
- **Párrafo 3 (PROBLEM):** *recently · yesterday · while · when · after · before · fortunately · eventually · as a result*
- **Párrafo 4 (NEXT STEPS):** *as for the next steps · after that · then · next · in the meantime · if everything goes according to plan · by [deadline]…*

## 3. Texto modelo de referencia (Model Answer)

> Our team is currently developing an online booking system for a hotel. In general, we divide the work between front-end and back-end tasks, but at the moment we are focusing on the reservation page and the mobile version.
>
> So far, we have completed the homepage, the room catalogue and the contact section. However, we haven't finished the payment system yet because we have been dealing with a security issue for the last few days. Apart from that, the project is progressing well.
>
> Yesterday, we had a problem with the booking form. While I was testing it, the website suddenly stopped saving new reservations. After checking the system, we discovered that a database setting had been changed by mistake. Fortunately, we had a recent backup, so we restored the previous configuration and solved the problem.
>
> As for the next steps, we are meeting the client tomorrow to discuss a few final changes. After that, we are going to start the final testing phase. If everything goes according to plan, by the end of next week we will have completed the main version of the website.

## 4. Redacción final entregada (`DAW Writing 1 - Project Status Update(hecho).pdf`)

- **Alumno:** Raúl Sal Romeo (`2º DAW Y`)

### Texto entregado (178 palabras)

> Our team normally **builds** *(Present Simple)* custom templates for online stores, and we **are currently developing** *(Present Continuous)* an e-commerce website for a local sports shop. At the moment, we **are working** *(Present Continuous)* on the product database and the user login system.
>
> So far, we **have successfully designed** *(Present Perfect)* the homepage and the shopping cart interface. However, we **haven't integrated** *(Present Perfect)* the payment gateway yet because we **have been trying** *(Present Perfect Continuous)* to resolve an API connection issue for the last two days. Apart from that, the progress is fantastic.
>
> Yesterday, we **experienced** *(Past Simple)* a major problem with the main server. While I **was uploading** *(Past Continuous)* new high-resolution product images, the testing website suddenly **crashed** *(Past Simple)*. After a quick technical check, we **discovered** *(Past Simple)* that someone **had deleted** *(Past Perfect)* a core configuration file by mistake. Fortunately, we **restored** *(Past Simple)* the backup quickly and **solved** it.
>
> As for the next steps, we **are having** *(Present Continuous for future arrangement)* a meeting with the client on Friday to review the interface design. After that, we **are going to begin** *(`be going to`)* the security testing phase. If everything goes according to plan, by the end of this month we **will have launched** *(Future Perfect)* the final version of the store.

### Checklist de verificación B2 cumplida
- [x] **150–180 palabras** (178 palabras exactas).
- [x] **4 párrafos claros** siguiendo la estructura *Now → Progress → Problem → Next steps*.
- [x] **9 formas verbales distintas** (*Present Simple, Present Continuous, Present Perfect, Present Perfect Continuous, Past Simple, Past Continuous, Past Perfect, `be going to`, Future Perfect*).
- [x] **Conectores naturales** (*currently, at the moment, so far, however, yet, apart from that, yesterday, while, after, fortunately, as for the next steps, after that, by the end of this month*).
- [x] **Vocabulario técnico web** (*custom templates, e-commerce, product database, user login system, shopping cart interface, payment gateway, API connection, server, crashed, core configuration file, backup, security testing*).
