## 📖 Cómo Usar Este Repo

1. **Clonar el repo**: `git clone <url>`
2. **Actualizar**: `git pull` antes de empezar a estudiar
3. **Hacer cambios**: crear rama (`git checkout -b rama`)
4. **Subir cambios**: `git push`
