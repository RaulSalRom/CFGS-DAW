Sobre el Proyecto

DAWConnect es un proyecto integrador que demuestra los conocimientos adquiridos durante el primer curso del CFGS en Desarrollo de Aplicaciones Web.

El proyecto combina una aplicación de consola en Java con gestión de datos, un frontend web responsive, una base de datos SQL completa, y documentación técnica.

Todo el código está versionado con Git y disponible en GitHub.

Stack Tecnológico

  • Java 21 (POO)
  • HTML5 + CSS3
  • JavaScript (Vanilla)
  • SQL (SQLite)
  • Git + GitHub
