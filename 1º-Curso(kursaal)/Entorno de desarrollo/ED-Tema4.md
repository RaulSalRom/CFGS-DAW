# ED-Tema4: UX vs UI

> Diseño de interfaces

## UX - User Experience (Experiencia de Usuario)

- Proceso general de cómo el usuario interactúa y "siente" el producto
- Objetivo: navegación lógica, eficiente, fluida
- Resolver necesidades del cliente
- **Usabilidad pura**

### Principios UX
- Facilidad de aprendizaje
- Eficiencia de uso
- Memorabilidad
- Prevención de errores
- Satisfacción del usuario

---

## UI - User Interface (Interfaz de Usuario)

- Capa visual e interactiva
- Tipografía, colores, botones, disposición (layout)
- Lo que hace ver atractivo el producto
- **Estética**

### Elementos UI
- Componentes interactivos
- Sistemas de diseño
- Paletas de color
- Tipografía
- Espaciado y alineación

---

## UX vs UI

| Aspecto | UX | UI |
|---------|----|----|
| Focus | Experiencia | Visual |
| Pregunta | ¿Cómo funciona? | ¿Cómo se ve? |
| Proceso | Investigación, wireframes | Diseño, prototipos |
| Output | Flujos de usuario | Mockups, componentes |
