LENGUAJES DE MARCAS - RESUMEN
DE
ENERO
**PSEUDOCLASES:** Una pseudoclase se utiliza para deﬁnir un estado especial de un elemento. Se
añade
a
un
selector
de
CSS
para
aplicar
estilos
cuando
el
elemento
cumple
una
condición
especíﬁca,
como
ser
el
primer
hijo
o
cuando
el
usuario
interactúa
con
él.
Las
pseudoclases
más
empleadas
son:
:link → Selecciona un enlace que no ha sido visitado. Es el estado base de
cualquier
hipervínculo.
:visited → Selecciona un enlace que el usuario ya ha pulsado y que está en su
historial
de
navegación.
:hover → Se activa cuando el usuario sitúa el puntero del ratón sobre un
elemento.
Es
la
más
utilizada
para
botones
y
menús.
:active → Se aplica en el momento en que se hace clic sobre un elemento
(mientras
se
mantiene
pulsado).
:focus → Se activa cuando un elemento (normalmente un input de formulario
o
un
enlace)
es
seleccionado
mediante
el
teclado
o
un
clic.
:ﬁrst-child → Selecciona el elemento siempre que sea el primer hijo dentro de
su
contenedor
padre.
:last-child → Selecciona el elemento siempre que sea el último hijo dentro de
su
contenedor
padre.
:nth-child(n) → Permite seleccionar uno o varios hijos especíﬁcos usando
números
(3),
palabras
clave
(even,
odd)
o
fórmulas
(2n).
:checked → Se aplica a los elementos de tipo checkbox o radio que están
marcados
por
el
usuario.
:disabled → Selecciona elementos de formulario que tienen el atributo de
"deshabilitado"
y
no
permiten
interacción.
:required → Selecciona aquellos campos de entrada que son obligatorios para
enviar
el
formulario.
:not(selector) → Se utiliza para seleccionar todos los elementos excepto el que
se
indica
dentro
del
paréntesis.
Es
muy
útil
para
excluir
elementos
especíﬁcos
de
un
estilo
general.
Por
ejemplo,
puedes
aplicar
un
borde
inferior
a
todos
los
elementos
de
una
lista
excepto
al
último
usando
:not(:last-child)
,
lo
que
ahorra
líneas
de
código.
:is(selector1, selector2, ...) → sirve para agrupar múltiples selectores y
aplicarles
el
mismo
estilo
de
una
sola
vez.
Es
muy
útil
para
evitar
repetir
código
cuando
quieres
que
varios
estados
(como
:hover,
:active
y
:focus)
disparen
la
misma
animación.
:has(selector) → Permite aplicar estilos a un elemento padre basándose en si
contiene
un
hijo
especíﬁco
o
si
ese
hijo
está
en
un
estado
concreto,
como
:has(:checked)
para
abrir
un
menú
desplegable
cuando
un
checkbox
es
marcado.
:placeholder-shown → Se activa únicamente cuando el texto de ayuda
(placeholder)
de
un
campo
de
entrada
es
visible.
Se
utiliza
para
crear
efectos
de
"etiquetas
ﬂotantes"
al
detectar
si
el
usuario
ha
empezado
a
escribir
o
no.
**PSEUDOELEMENTOS:** 
Un pseudoelemento se utiliza para aplicar estilos a partes especíﬁcas de un
elemento.
Por
ejemplo,
se
puede
usar
para
dar
estilo
a
la
primera
letra
o
línea
de
un
elemento,
o
para
insertar
contenido
antes
o
después
del
contenido
de
un
elemento.
La
sintaxis
estándar
utiliza
dos
puntos
dobles
(::)
para
diferenciarlos
de
las
pseudoclases.
Los
pseudoelementos
más
utilizados
son:
::before → Crea un pseudoelemento que es el primer hijo del elemento
seleccionado.
Se
utiliza
habitualmente
para
añadir
contenido
decorativo
mediante
la
propiedad
"content".
::after → Crea un pseudoelemento que es el último hijo del elemento
seleccionado.
Al
igual
que
before,
requiere
la
propiedad
"content"
para
ser
visible.
::ﬁrst-letter → Se utiliza para añadir un estilo especial a la primera letra de la
primera
línea
de
un
texto
(muy
común
para
crear
letras
capitulares).
::ﬁrst-line → Se utiliza para aplicar estilos únicamente a la primera línea de un
bloque
de
texto.
El
estilo
cambiará
dinámicamente
si
la
ventana
cambia
de
tamaño
y
la
línea
se
corta
en
un
punto
diferente.
::selection → Se aplica a la parte de un documento que ha sido seleccionada o
resaltada
por
el
usuario
(por
ejemplo,
al
arrastrar
el
ratón
sobre
un
texto).
Solo
admite
algunas
propiedades
como
color
y
background.
::placeholder → Selecciona el texto de ayuda que se muestra dentro de un
elemento
de
entrada
(input)
antes
de
que
el
usuario
escriba
algo.
::marker → Selecciona el marcador de los elementos de una lista (como el
punto
de
una
lista
desordenada
o
el
número
de
una
lista
ordenada).
Los pseudoelementos tienen una especiﬁcidad baja (1 punto de elemento).
Solo
se
puede
aplicar
un
solo
::before
y
un
solo
::after
a
cada
elemento;
si
deﬁnes
dos
veces
el
mismo,
el
segundo
sobrescribirá
al
primero
por
la
cascada
de
CSS.
**ESPECIFICIDAD:** 
La especiﬁcidad es el conjunto de reglas que aplican los navegadores para
determinar
qué
valores
de
propiedad
CSS
son
más
relevantes
para
un
elemento
y,
por
tanto,
serán
aplicados.
Se
activa
cuando
hay
dos
o
más
reglas
que
apuntan
al
mismo
elemento:
la
regla
con
la
especiﬁcidad
más
alta
"gana".

LA REGLA !important
Se utiliza para añadir más importancia a una propiedad de la que tendría
normalmente.
Si
la
usas,
esta
ignorará
todas
las
reglas
de
especiﬁcidad
previas para esa propiedad especíﬁca. No es un selector, sino un modiﬁcador
que
se
aplica
al
valor
de
la
propiedad.
La regla debe escribirse inmediatamente después del valor de la propiedad y
antes
del
punto
y
coma.
**Ejemplo:** 
color:
red
!important;
.
Si
se
escribe
mal
(por
ejemplo,
el
signo
de
exclamación
después
de
la
palabra
o
fuera
del
punto
y
coma),
el
navegador
la
ignorará
y
aplicará
la
especiﬁcidad
normal.
Cuando dos reglas en conﬂicto se aplican al mismo elemento y una tiene
!important,
esta
última
vence
siempre.
Da
igual
que
la
otra
regla
venga
de
un
ID
(100
pts),
de
una
Clase
(10
pts)
o
de
un
Estilo
en
Línea
(1000
pts).
El
!important
"rompe"
la
tabla
de
puntos.
**IMPORTANTE:** Si hay conﬂicto entre dos !important, en ese caso, la "magia"
de
ignorar
la
especiﬁcidad
desaparece
entre
ellos
y
el
navegador
vuelve
a
usar
las
reglas
normales
para
desempatar:

REGLAS CSS (@)
Son identiﬁcadores que comienzan con un símbolo @ seguido de un
identiﬁcador.
Funcionan
como
"comandos"
globales
para
la
hoja
de
estilos.
Las
más
empleadas
son:
@media → Es la reina del diseño responsivo. Permite aplicar estilos solo si se
cumplen
ciertas
condiciones
(como
el
ancho
de
la
pantalla).
**Ejemplo:** 
@media
(max-width:

### 600px)
{
...
}
→
(solo
se
aplica
en
pantallas
pequeñas).
@import : Sirve para incluir una hoja de estilos dentro de otra. Debe ir siempre
al
principio
del
archivo
CSS.
@keyframes : Se utiliza para crear animaciones. Aquí deﬁnes los pasos (el
"inicio"
y
el
"ﬁn")
de
un
movimiento.
@font-face : Permite cargar fuentes personalizadas que no están instaladas
en
el
ordenador
del
usuario
(como
una
fuente
descargada
de
Google
Fonts).
@charset : Deﬁne la codiﬁcación de caracteres del archivo (normalmente
UTF-8).
Debe
ser
la
primerísima
línea
del
archivo.
@container : Similar a @media, pero en lugar de mirar el tamaño de la
pantalla,
mira
el
tamaño
de
un
elemento
padre
(contenedor).
Es
lo
más
moderno
en
CSS.
@layer : Sirve para declarar "capas de cascada". Ayuda a organizar qué partes
del
CSS
son
más
importantes
que
otras,
independientemente
de
la
especiﬁcidad.
@supports : Comprueba si el navegador del usuario es compatible con una
función
especíﬁca
de
CSS
antes
de
aplicarla
(como
un
"test"
de
compatibilidad).
@page : Se usa para modiﬁcar aspectos del documento cuando se va a
imprimir
(márgenes
de
la
hoja,
saltos
de
página).
