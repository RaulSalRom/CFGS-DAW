## Ejercicio 1

**IP:** 10.46.173.85  
**Máscara:** 255.255.240.0 → /20

### Calcular dirección de subred (network ID)

```
IP:      10.46.173.85  → 00001010.00101110.10101101.01010101
Mask:    255.255.240.0 → 11111111.11111111.11110000.00000000
AND:     ---------------------------------------------------
Network: 10.46.160.0   → 00001010.00101110.10100000.00000000
```

### Calcular dirección de broadcast

```
Network: 00001010.00101110.10100000.00000000
Host bits (12): todos a 1
Broadcast:      00001010.00101110.10101111.11111111 → 10.46.175.255
```

**Solución:** La opción correcta es la **a**.

| Opción | Network ID | Broadcast |
|--------|-----------|-----------|
| a ✓ | 10.46.160.0 | 10.46.175.255 |
| b | 10.46.172.0 | 10.46.175.255 |
| c | 10.46.160.0 | 10.46.191.255 |
| d | 10.46.168.0 | 10.46.183.255 |

## Ejercicio 2

**Red clase B** → máscara por defecto /16 (255.255.0.0)

### Requisitos
- Subredes actuales: 35
- Subredes futuras: +20 → **Total subredes necesarias: 55**
- Hosts por subred: **1000**

### Calcular bits de subred

2^n ≥ 55 → n = 6 (2^6 = 64 ≥ 55)

### Calcular bits de host

2^h - 2 ≥ 1000 → 2^h ≥ 1002 → h = 10 (2^10 - 2 = 1022 ≥ 1000)

### Máscara resultante

```
Bits red:     16 (Clase B)
Bits subred:   6
Bits host:    10
Total:        32 ✓

Máscara: /22 → 255.255.252.0
                 11111111.11111111.11111100.00000000
```

**Solución:** La opción correcta es la **b (255.255.252.0)**.

| Opción | Máscara | Subredes (2^6=64 ≥ 55) | Hosts (2^10-2=1022 ≥ 1000) |
|--------|---------|------------------------|----------------------------|
| a | 255.255.248.0 (/21) | 2^5 = 32 ❌ | 2^11-2 = 2046 ✓ |
| **b ✓** | **255.255.252.0 (/22)** | **2^6 = 64 ✓** | **2^10-2 = 1022 ✓** |
| c | 255.255.254.0 (/23) | 2^7 = 128 ✓ | 2^9-2 = 510 ❌ |
| d | 255.255.240.0 (/20) | 2^4 = 16 ❌ | 2^12-2 = 4094 ✓ |

## Ejercicio 3

**IP:** 192.168.50.0/24

### a) Máscara para 30 hosts por subred

2^h - 2 ≥ 30 → 2^h ≥ 32 → h = 5 (2^5 - 2 = 30)

```
Máscara: /24 + (32 - 24 - 5) = /27
         /27 → 255.255.255.224
               11111111.11111111.11111111.11100000
```

### b) Número máximo de subredes

```
Bits de subred = 27 - 24 = 3 bits
Nº subredes = 2^3 = 8 subredes
```
