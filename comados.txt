# Comandos básicos para Fedora

## 📦 Sistema y Paquetes (DNF)

```bash
sudo dnf update              # Actualizar todo el sistema
sudo dnf install <paquete>  # Instalar un paquete
sudo dnf remove <paquete>    # Eliminar un paquete
dnf search <término>         # Buscar paquetes
dnf list installed           # Listar paquetes instalados
sudo dnf upgrade             # Actualizar paquetes
```

## 🔧 Servicios y Procesos

```bash
sudo systemctl start <servicio>     # Iniciar servicio
sudo systemctl stop <servicio>     # Detener servicio
sudo systemctl restart <servicio>  # Reiniciar servicio
sudo systemctl status <servicio>  # Ver estado
sudo systemctl enable <servicio>   # Habilitar al inicio
sudo systemctl disable <servicio>  # Deshabilitar al inicio

ps aux                             # Ver procesos
ps aux | grep <nombre>            # Buscar proceso
kill -9 <PID>                     # Matar proceso (fuera)
pkill -f <nombre>                 # Matar por nombre
top / htop                        # Monitor de procesos
```

## 📁 Archivos y Directorios

```bash
ls -la                 # Listar con detalles
ls -lh                # Listar tamaño legible
cd ~                  # Ir a home
cd -                  # Ir al directorio anterior
pwd                   # Mostrar ruta actual
mkdir -p <ruta>       # Crear directorio(s)
rm -rf <ruta>         # Eliminar directorio(s) forzosamente
cp -r <origen> <dest> # Copiar recursivo
mv <origen> <dest>    # Mover/Renombrar
touch <archivo>       # Crear archivo vacío
cat <archivo>         # Ver contenido
less <archivo>        # Ver contenido (paginado)
tail -f <archivo>    # Ver contenido en tiempo real
head -n <líneas> <archivo>  # Ver primeras líneas

# Permisos
chmod +x <archivo>   # Dar permiso de ejecución
chmod 755 <archivo>  # Permisos estándar
chown user:group <archivo>  # Cambiar propietario
```

## 🌐 Red

```bash
ip a                   # Ver IPs (nueva命令)

ip route               # Ver tabla de rutas
ping <host>            # Hacer ping
curl <url>             # Descargar/Hacer request

scp archivo user@host:/ruta   # Copiar por SSH

sudo firewall-cmd --add-port=8080/tcp  # Abrir puerto
sudo firewall-cmd --remove-port=8080/tcp  # Cerrar puerto

# DNS

```

## 🔍 Búsqueda

```bash
find /ruta -name <archivo>      # Buscar por nombre
find /ruta -type d              # Buscar directorios
find /ruta -type f -size +100M  # Buscar archivos grandes
grep -r "<texto>" <directorio> # Buscar texto en archivos
grep -i "<texto>" <archivo>    # Buscar sin importar mayúsculas
which <comando>                # Ruta de un comando
whereis <comando>              # Binarios, fuentes, manpages
locate <archivo>               # Buscar rápido (requiere updatedb)
```

## 📦 Compresión

```bash
# tar
tar -cvf archivo.tar <directorio>  # Crear
tar -xvf archivo.tar               # Extraer
tar -cvzf archivo.tar.gz <dir>    # Crear .tar.gz
tar -xvzf archivo.tar.gz          # Extraer .tar.gz

# zip
zip -r archivo.zip <directorio>   # Comprimir
unzip archivo.zip                 # Extraer

# 7z
7z a archivo.7z <directorio>      # Comprimir
7z x archivo.7z                   # Extraer
```

## 🐳 Docker

```bash
sudo systemctl start docker    # Iniciar Docker
docker ps                      # Ver contenedores activos
docker ps -a                   # Ver todos los contenedores
docker images                  # Ver imágenes
docker pull <imagen>          # Descargar imagen
docker run -it <imagen>       # Ejecutar imagen interactivo
docker exec -it <container> /bin/bash  # Entrar en contenedor
docker stop $(docker ps -aq)  # Detener todos
docker rm $(docker ps -aq)    # Eliminar todos
docker rmi $(docker images -q) # Eliminar todas las imágenes
```

## 📝 MarkItDown

Convierte archivos (PDF, Word, Excel, PowerPoint, imágenes, etc.) a Markdown.

### Instalación

```bash
pip install 'markitdown[all]'  # Todas las dependencias
pip install 'markitdown[pdf,docx,pptx,xlsx]'  # Solo las principales
```

### Uso CLI

```bash
markitdown archivo.pdf              # Convertir a stdout
markitdown archivo.pdf -o salida.md # Guardar en archivo
cat archivo.pdf | markitdown        # Por tubería
markitdown archivo.pdf -o salida.md -x pdf  # Forzar extensión
```

### Uso Python

```python
from markitdown import MarkItDown

md = MarkItDown()
result = md.convert("documento.pdf")
print(result.text_content)
```

## 💎 Obsidian

Notas en Markdown con interlinked. Excelente para crear Second Brain.

### Instalación

```bash
# Descargar desde https://obsidian.md/download
# Extraer AppImage
./Obsidian-*.AppImage --appimage-extract
ln -s squashfs-root/obsidian ~/.local/bin/obsidian

# Ejecutar
obsidian --no-sandbox
```

### Comandos básicos

| Atajo | Acción |
|-------|--------|
| `Ctrl+P` | Paleta de comandos |
| `Ctrl+Shift+F` | Buscar en todos los archivos |
| `Ctrl+E` | Vista previa/Edición |
| `Ctrl+Shift+S` | Vista lateral |
| `Ctrl+O` | Abrir quick switcher |
| `Ctrl+Shift+H` | Reemplazar en archivos |

### Markdown en Obsidian

```markdown
# Título         → Encabezado 1
## Título       → Encabezado 2
[[enlace]]      → Enlace a otra nota
[[enlace#sección]] → Enlace a sección
![[imagen.png]] → Insertar imagen
![[nota]]       → Incrustar nota
- [ ] tarea    → Tarea pendiente
- [x] tarea    → Tarea completada
> cita         → Blockquote
```
